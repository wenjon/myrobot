# 数字人头部交互式对话 Demo — 需求文档

- 状态: Draft

## 1. 项目定位

一个会说话、有表情、能互动的**桌面 3D 数字人**。
在浏览器里渲染，用自然语言对话驱动口型、表情、头部动作；
后端 Python 编排 LLM / TTS / 记忆 / 工具。

用户价值：
- **陪伴感**：桌面上有个"活的"小人能聊天，不是冷冰冰的对话框
- **展示价值**：全链路流式语音交互的可视化 Demo
- **研究载体**：可以快速试新模型、新表情、新音色、新交互模式

## 2. 核心用户与场景

### 2.1 目标用户
- 开发者 / 爱好者：想折腾数字人交互的技术玩家
- 桌面陪伴：开着窗口当一个会动的小助手
- 展示 / Demo：AI 数字人能力的可视化展示

### 2.2 典型场景

| 场景 | 描述 | 优先级 |
|---|---|---|
| 日常闲聊 | 随便聊点啥，数字人有表情有动作 | P0 |
| 问事实 / 查信息 | 问天气、查新闻，数字人联网搜索后回答 | P0 |
| 桌面陪伴 | 开着窗口不说话，小人也会自己眨眼、转头、动一下 | P1 |
| 记住用户 | 多次对话后记得用户偏好、名字、习惯 | P1 |
| 展示演示 | 向别人展示"AI 数字人能干嘛" | P1 |
| 人物切换 | 换成不同的脸型 / 发型 / 服装 | P2 |
| 摄像头跟随 | 有人走过来时数字人转头盯着看 | P2 |

## 3. 功能需求

### 3.1 对话（P0）

- [x] 文本输入 + 回车发送
- [x] 语音输入（浏览器 Web Speech Recognition，可选）
- [x] 流式回答 —— LLM 边产出边播报，不等整段结束
- [x] 自动分句 —— 收到一小段就开口，不需要等整句
- [x] 打断（barge-in）—— 用户可以随时打断，数字人会自然收尾而不是硬切
- [x] 新对话 / 清空历史
- [x] 多轮上下文 —— 记得前面说过什么

### 3.2 数字人模型与表现（P0）

#### 3.2.1 模型要求

| 项 | 要求 | 为什么 |
|---|---|---|
| 格式 | `.glb`（GLTF 二进制） | Three.js 直接加载，无需额外插件 |
| 口型 | **必须** 15 个 Oculus viseme（viseme_sil ~ viseme_U） | 15 个缺任何一个，那个音的口型就出不来，这是第一道硬门槛 |
| 表情 | 推荐 52 个 ARKit blendshape | 缺了就只能做有限的几种表情 |
| 骨骼 | 必须有 `Head` / `Neck` | 没有的话点头摇头只能转整个人，很假 |
| 眼球骨 | 推荐有 `LeftEye` / `RightEye` | 注视时瞳孔一起转才真实，没有也能靠 blendshape 凑 |
| 躯干骨 | 推荐有 `Spine1` | 呼吸起伏用，没有不影响核心功能 |
| 面数 | ≤ 15K 三角面 | 笔记本集显也要稳定 60fps |
| 体积 | ≤ 8 MB | 首屏加载可接受 |

#### 3.2.2 表情系统（18 种）

持续状态表情（保持到下一次切换）：

| 类别 | 表情 | 触发方式 |
|---|---|---|
| 基础 6 种 | 平静 / 开心 / 悲伤 / 生气 / 惊讶 / 疑惑 | 模型原始版本已有 |
| 新增 12 种 | 害羞 / 调皮 / 无语 / 思考 / 尴尬 / 得意 / 委屈 / 惊恐 / 厌恶 / 困倦 / 撒娇 / 期待 | 增强情绪表达 |

表情由 LLM 通过 `[表情:x]` 行内标记触发。不对称是关键设计原则：真人表情很少左右完全一样。

#### 3.2.3 动作系统（21 种）

一次性动作（触发后自动回位）：

| 类别 | 动作 | 说明 |
|---|---|---|
| 头颈 | 点头、摇头、歪头 | 分层转颈骨（Neck 60% + Head 40%），不是转整个模型 |
| 注视 | 看左 / 看右 / 看上 / 看下 / 环视 / 对视 | 眼睛先到，头随后跟上，弹道式运动 |
| 眨眼 | 眨眼 / 眨左眼 / 眨右眼 | 单眼眨就是 wink |
| 面部叠加 | 挑眉 / 单挑眉 / 皱眉 / 鼓腮 / 撅嘴 / 吐舌 / 咬唇 / 努嘴 | 在当前表情之上叠加一层，结束回落，不覆盖表情 |

动作由 LLM 通过 `[动作:x]` 行内标记触发。

#### 3.2.4 口型同步（P0）

- 15 个 Oculus viseme 全量驱动
- 逐字触发：每念一个字切一次口型
- 平滑过渡：不是瞬间切换，是插值逼近
- 口型精度：demo 级（拼音粗分，不是真音素级），能看出来在说话即可
- 说话时 jawOpen 跟随张口类 viseme

#### 3.2.5 自发微动（P1，"活着"感来源）

没有指令时也在动，这是去掉"雕像感"的关键：

- **随机扫视**（saccade）：1.2~3.8s 一次，小幅度眼球移动
- **头部微摆**：低频缓慢摆动，幅度很小
- **呼吸起伏**：`Spine1` 轻微上下，约 15 次/分
- **自然眨眼**：1.8~4.3s 随机间隔

这些不依赖任何 LLM 输出，纯本地循环驱动。

#### 3.2.6 倾听姿态（P1）

被用户打断时的自然收尾：

- 收嘴（停止当前口型）
- 歪头约 7°（侧耳倾听感）
- 眉根微抬 + 双眼微睁大（专注表情）
- 1.5 秒内如果没新内容，自动恢复

#### 3.2.7 可换脸（P2）

- 模型文件可替换，代码不改
- 有预览页可试驱表情/动作/口型后再决定
- 自动兼容性检测：加载前就知道 viseme 够不够、骨骼缺不缺
- 不兼容的模型会被标红，不会强行加载导致崩

#### 3.2.8 非功能要求

| 项 | 指标 |
|---|---|
| 渲染帧率 | 60fps（普通集显） |
| 表情切换过渡 | 平滑（无跳变） |
| 模型加载时间 | < 3s（2.7MB 当前模型） |
| 不说话时的"活着"感 | 必须有，不能像照片 |
| 多种分辨率自适应 | 支持（相机自动对准头部） |

### 3.3 语音（P0）

- [x] Edge 神经语音合成（默认，自然度高）
- [x] 浏览器 Web Speech 兜底（断网/未装 edge-tts 时）
- [x] 韵律引擎 —— 句内抑扬顿挫，播音腔 / 日常口语 / 无韵律 三档
- [x] 表情驱动声音情绪 —— 开心偏快偏高、悲伤偏慢偏低，视听一致
- [x] 音量渐弱软停 —— 被打断时自然收尾，不是"咔"一下断掉
- [x] 语速/音高/音量可调

### 3.4 工具调用（P1）

- [x] function calling —— LLM 决定是否调用工具
- [x] 联网搜索（Tavily）—— 问实时信息/天气/新闻时自动搜
- [x] 工具注册表 —— 加新工具只需写一个函数 + 装饰器
- [x] 工具执行状态提示 —— "正在联网搜索…"显示在状态栏

### 3.5 记忆（P1）

- [x] 三层记忆：工作记忆（当前轮）/ 情景记忆（对话历史）/ 语义记忆（用户画像）
- [x] 用户画像自动提炼 —— 从对话里抽取稳定信息（名字/偏好/习惯）
- [x] 冲突确认 —— 画像变更有冲突时弹卡让用户拍板
- [x] 本地持久化 —— JSON 文件存盘，刷新不丢

### 3.6 可换形象（P2）

- [x] 模型文件可替换 —— 换一个 glb 文件就能换脸
- [x] 预览页 —— 独立页面试驱表情/动作/口型，选好了再换上
- [x] 兼容性检测 —— 自动识别 viseme / ARKit / 骨骼匹配度

### 3.7 摄像头感知（P2，规划中）

- [ ] 双目摄像头感知人体接近
- [ ] 数字人眼睛 / 头部跟随注视方向
- [ ] 按距离分级反应（远处瞥一眼 / 近处转头 / 很近打招呼）
- [ ] 人离开后延迟回落，不是立刻弹回

详见规格文档第 19 章（规划中）。

## 4. 非功能需求

### 4.1 性能
- 首句延迟 < 2s（从发送到开口说话）
- 句间间隔 < 300ms（流式分句 + 预取合成）
- 3D 渲染 60fps（普通笔记本集显也能跑）
- 模型文件 < 8MB（首屏加载可接受）

### 4.2 可靠性
- TTS 失败自动降级（Edge → Web Speech），数字人不能哑
- 网络波动不崩溃，WS 自动重连
- 断网时还能本地对话（配本地 LLM 时）

### 4.3 可扩展性
- LLM 供应商可切换（ark / llamacpp / ollama），上层不改
- TTS 引擎可替换（Edge / Web Speech，预留本地 TTS 接口）
- 工具可插拔（注册制，加一个工具写一个函数）
- 表情可扩展（加一行配置 + 同步 prompt + 同步白名单）

### 4.4 安全与隐私
- API Key 不入库，走 .env
- 用户画像 / 对话历史存在本地，不上传
- 密钥扫描 CI，防止误提交

## 5. 约束与假设

### 5.1 约束
- **无物理硬件**：纯软件模拟，不涉及伺服电机 / 嵌入式
- **Windows 环境**：主要在 Windows 桌面运行
- **浏览器渲染**：前端必须在浏览器里跑，不能依赖本机桌面程序
- **GPU 为集显或 AMD**：不能依赖 CUDA（Wav2Lip / SadTalker 等路线走不通）

### 5.2 假设
- 用户有稳定的网络（Edge TTS + 云端 LLM 需要联网）
- 用户熟悉基本的命令行操作（安装 Python、填 .env、启动服务）
- 本地 LLM 为可选项，不是默认配置

### 6.1 本期做了（Done）

### 6.2 明确不做（Out of scope）
- ❌ 物理机器人 / 伺服驱动

- ❌ 多用户 / 多人同时对话
- ❌ 生产级部署 / 高并发
- ❌ 手机端适配（能跑但不优化）
- ❌ 完整的 VRM 支持（仅支持 ARKit + Oculus 标准的 glb）

## 7. 验收标准（Demo 级）

详见规格文档第 8 章。核心几条：

1. 发一句话，3 秒内数字人开口说话，且口型同步
2. 打断后 200ms 内停止说话并进入倾听姿态
3. 18 种表情全部能在预览页触发，没有 blendshape 的模型会被检测并标红
4. 刷新页面后对话历史和用户画像不丢
5. 网络断开时数字人不会崩，会降级到 Web Speech 或提示错误
